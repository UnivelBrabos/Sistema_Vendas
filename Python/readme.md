## Info 
Já deixei configurado um ambiente virtual python então é só selecionar o interpretador com `Ctrl + Shift + P`
Aí você vai escolher o `supabase_env`. e vai pegar esse caminho `./supabase_env/Scripts/python.exe`  
Se a main não rodar, vai no terminal e escreve isso `pip install -r requirements.txt`

### Seguinte
A documentação pode ser acessada em localhost:8000/docs ou localhost:8000/redoc
