# Sistema Vendas
# CRM de Vendas

## Sobre o Projeto

Este é um CRM de vendas desenvolvido como um trabalho acadêmico. O sistema consiste em:

- 📱 **Aplicação Mobile (Flutter)** para emissão de vendas.
- 🖥️ **Aplicação Desktop (C#)** que simula um Power BI para controle de vendas e vendedores.
- 🔄 **Middleware (Python)** para gerenciar requisições e interações com o banco de dados Supabase.

---

## Tecnologias Utilizadas

- **Flutter** 📱: Aplicação mobile para emissão de vendas.
- **C#** 🖥️: Aplicação desktop para controle e análise de dados.
- **Python** 🐍: Middleware para comunicação entre aplicações e banco de dados.
- **Supabase** 🗄️: Banco de dados utilizado para armazenar informações.

---

## Funcionalidades

### 📊 Controle "Geral" (Desktop - C#)

- Processamento de dados (BI);
- Controle de produtos;
- Gestão de funcionários;
- Controle de clientes.

### 🛒 Emissão de Vendas (Mobile - Flutter)

- Emissão de vendas;
- Autenticação (login e senha);
- Interface amigável;
- Suporte ao funcionamento offline (salvar em documentos);
- Cadastro de novos clientes.

### 🔄 Middleware (Python)

- Gerenciamento de requisições;
- Tratamento de dados;
- Interação com o banco de dados (pegar e devolver informações);
- Segurança contra invasões.
